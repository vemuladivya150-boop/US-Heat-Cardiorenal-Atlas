# U.S. Heat-Cardiorenal Vulnerability Atlas

An interactive county-level spatial epidemiology atlas examining extreme heat exposure, cardiometabolic susceptibility, social vulnerability, and age-adjusted heart-disease mortality across the United States.

## Author

Divya Vemula

## Study period

2016–2020

## Atlas components

- Extreme heat exposure
- Clinical susceptibility
- Social vulnerability
- Age-adjusted heart-disease mortality
- County-level Heat-Cardiorenal Vulnerability (HCV) score
- Interactive 3D spatial visualization

## Visualization design

Map color represents the selected epidemiologic vulnerability layer. 3D extrusion height represents age-adjusted heart-disease mortality. A selected county is highlighted in gold and elevated for visual focus.
